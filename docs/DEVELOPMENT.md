# Airplanes 研发基线

## 已确定的产品边界

1. 版本入口同时提供“净空体验”和“1940 · 海峡空战”。
2. 净空体验保留 Dash Fly revision 35 的核心世界、默认飞行行为、喷气机和三种相机，后续不把战斗规则强加给它。
3. 英德空战使用原创螺旋桨机体，不把现代喷气机换色后充当二战机型。
4. 首版完整支持单人对 AI，不声称已完成联网多人或严谨历史模拟。
5. 不给上游未明确授权的源码补写宽泛开源许可证。新增代码与上游衍生部分分别记录。

## 架构

`src/engine` 负责飞行位置、相机、环境与像素渲染；`src/game/combat.js` 负责敌人、子弹、战斗规则、任务与结算。`app.js` 负责输入和界面。

原版场景新增可选 `hidePlayer` 与 `manualControl`。两者默认 false，回归测试验证原版三视角逐像素不变。战斗模式将它们设为 true，读取权威玩家位置，生成独立战斗状态，通过 `drawActors` 绘制双方飞机。

```js
scene.step(dt);
const pose = scene.getFlightState();
combat.step(dt, pose, { firing });
const pixels = scene.render();
scene.drawActors([playerActor, ...enemyActors]);
// 之后上传pixels，再叠加HUD、弹道和效果。
```

所有飞机一次传入 `drawActors`，它为整个列表使用统一 actor 深度缓冲。外部模型坐标已居中，x 横向、y 朝机首、z 向上。颜色为小端 RGBA 缓冲对应的 `0xAABBGGRR`。

战斗首版固定俯视。追尾和座舱涉及更大的中间画布、相机滚转、深度和仪表遮挡；不能只开放切换按钮后声称战斗三视角可用。

## 现有任务与皮肤

任务：海峡巡逻 6 击落、自由猎杀 8 击落、生存 180 秒。每个任务有明确完成/失败条件和重开。

RAF：英伦绿棕、海岸灰绿、午夜巡航、纪念银翼。

德国空军：灰绿猎隼、沙漠黄沙、冬季白霜、夜雾石墨。

这些为艺术涂装，避免在 UI 中虚构真实中队编号或精确历史年份使用情况。

## 下一批候选工作

- 基于真实手机测试调整转弯、瞄准辅助、画布分辨率、触摸区域和性能。
- 精修螺旋桨动画、座舱模型与敌机烟雾，增加机型时同时补齐几何和可辨识轮廓。
- 加入经过验证的海峡地形、机场、护航/轰炸机拦截目标，不能仅把旧任务改名。
- 将引擎高度查询与碰撞规则明确分离；首版保留地形安全高度，避免突然改变原版飞行体验。
- 在稳定的世界投影接口上扩展战斗追尾镜头，再设计历史机型座舱。
- 最后评估多人：服务端权威模拟、快照与延迟处理、反作弊、断线恢复。这一层目前没有实现。

## 验收要求

变更原引擎时运行逐像素回归；变更战斗规则时覆盖真实枪弹命中与波次；界面变化验证桌面和手机。已有用户存档损坏或浏览器禁用存储时，仍须可以正常进入游戏。
