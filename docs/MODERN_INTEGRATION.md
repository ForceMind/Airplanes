本次实际整合来源：`https://2kp1v13.sharehtml.org/`，页面标题为 **Fighter + Guns v9 — a combat fork of Dash’s jet game**。原文件 524,270 字节，SHA-256：

`8c591be9712fafc9d842a508e6780981f08c2652669e00f6edbd772086cf5bb7`

该文件包含完整内联 JavaScript 和样式，不依赖远程游戏服务。它的原生实现已经有俯视、追尾、座舱、武器、敌人、技能树、成就、存档和按键设置。本次没有按截图重新推测这些功能。

## 集成方式

三个入口：`#free`、`#modern`、`#hangar` / `#combat`。现代战斗代码本地存储在仓库，通过同源本地 iframe 运行，隔离 CSS、键盘输入、计时器与音效；这不是嵌入 ShareHTML 外站，也不是共享两个独立引擎的一套游戏状态。

入口负责载入、视角与暂停按钮、离开时销毁子页。桥接消息校验来源窗口及同源 origin，只接受明确命令。CSP 禁止网络连接及外部资源；脚本原本就是内联构建，因此保留内联执行而非声称严格无内联 CSP。iframe 同源与脚本权限并非针对恶意同源代码的安全沙箱。

原始快照不改动。`scripts/import-modern.mjs` 的生成适配仅四项：原生相机切换接口、独立 localStorage 前缀、离线 CSP、本地 bridge.js。正常构建只读取仓库中的固定快照；显式 `--download` 才获取来源，并校验固定哈希，来源变更直接失败，不静默导入新代码。

现有原网址下的浏览器存档不能自动读取（不同站点 origin）。Airplanes 下的新存档与二战进度独立。

## 视角与操作

喷气空战默认追尾，原生 Space / V、触屏 View 和外壳视角按钮均循环三视角。原生 F 开枪、R 导弹、Q EMP、E 热诱弹、P / Esc 暂停；原生按键自定义继续可用。

二战的 V / 视角按钮循环三视角，空格仍射击。外部飞机、三叶桨和弹道采用实际镜头投影与遮挡；进入座舱隐藏玩家机体。新增活塞机仪表框为近似表现，不是精确历史座舱。敌机入场使用当前相机，透视镜头从画面侧外接近，避免把敌机一路放到地图重复边界之外。

运行 `npm run check`、`npm test`、`npm run build`、`npm run test:browser`。浏览器流程覆盖三入口、原飞行回归、英德武器、三视角、现代原生 F/R 开火、原生存档与成就菜单、暂停/退出/重入，以及原生移动端视角与射击按钮。只把实际运行通过的检查称为通过；功能在原始构建中存在不代表每一项高波次内容已逐项试玩。
